# AutoCache project website

[Live website](https://vibe-hust.github.io/autocache_page/) · [Research code](https://github.com/vibe-hust/autocache_code)

This repository hosts the complete public AutoCache project page, including its
images, videos, scripts, stylesheets, and any accompanying documents.

## Edit and publish

Edit `index.html`, the scripts and stylesheets, or files under `assets/`.
GitHub Pages publishes the root of `main` automatically after each push.
No installation or build step is required; `.nojekyll` disables Jekyll.

`project-meta.css` is a local copy of the author and project-link styles, so this
website can be deployed independently of the VibeLab homepage.

The previous URL, https://vibe-hust.github.io/autocache/, redirects to this site.
